# Review is a separate read-only task that gates the PR

In v1 the Hallmark Guild inspects code only: a branch or commit range on a registered Site against its writ, whether produced by Masonry or already existing (an external branch or PR). Chancery's specs and tickets and Survey's findings are not reviewed by the Guild; the developer approves specs and tickets, and Survey handbacks carry their own evidence and uncertainty. The Archwright starts Hallmark after Masonry's handback (ADR 0021 amends this: as the Plan's `review` step through `start_step`, not a separate `request_review` path), a fresh Warden run sharing no context with the builder, so the forked `implement-spec` drops its own final `code-review` (Masonry's Warden still inspects each piece). The Fix and Build Jigs include a Review step; the Review Jig is Review alone.

The Spec axis uses the writ if one is linked, else the Plan step's brief and the Job's original request recorded in the Works, else nothing; the verdict names which it used, and with nothing the axis is not evaluated and the overall verdict cannot be pass. Each axis is pass, fail or not evaluated, findings carry file and line, severity and reason, and Hallmark reports only. The Archwright's PR go-ahead (ADR 0008) requires an overall pass; on a fail the Archwright re-issues the work to Masonry once automatically with the findings as constraints and re-reviews (ADR 0021: as a second attempt of the build and review steps, not new steps), and a second fail parks the Job in the Needs-you inbox. This Job-level round is separate from the Warden's per-piece rework limit (ADR 0006). The `pr` skill belongs to the Masonry Warden, which opens the PR; Hallmark keepss `code-review` only, and `triage` stays assigned to Hallmark with no Jig until the deferred Triage Jig.

Amended by ADR 0028: review gates the PR by Plan ordering only (the `open-pr` step is blocked by Review); the Works does not enforce it on the push. Amended by ADR 0029: Review's independence comes from sharing no context with the builder, not from being a fresh run.
