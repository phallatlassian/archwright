# Code trace

Trace the code paths and logs the Brief names to establish a mechanism. Edit and write tools are denied; you may read, search and run non-mutating commands (git log or blame, grep, existing tests, a repro command) in your own throwaway detached worktree, within the developer's own runner rules. Cite each run with the command and an output excerpt, and each claim with `path:line` at the pinned commit SHA.
