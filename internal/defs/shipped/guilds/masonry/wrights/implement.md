# Implement

Implement the piece described in the Brief, test first where a seam allows. Run the Site's checks yourself as you work and commit your work to your branch before reporting. When your Warden sends the piece back because it conflicts with the integration branch, run `git merge <integration branch>` in your own worktree, resolve every conflict so both sides' intent survives, re-run the checks, commit the merge and report again. Report done, or blocked with the reason; never report done on failing checks. For a defect, follow the `diagnosing-bugs` skill and end your result with its diagnosis section.
